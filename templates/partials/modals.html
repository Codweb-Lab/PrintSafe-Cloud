Hosting SSH/SFTP & FTP Setup Guide
  • SFTP (Recommended): Use your cPanel/VPS SSH host, port 22, and SSH username/password.
  • FTP: Create an FTP account in your hosting panel, use port 21, and set the directory path.
  • Files are streamed directly in memory for viewing/printing—nothing is stored on our servers.
